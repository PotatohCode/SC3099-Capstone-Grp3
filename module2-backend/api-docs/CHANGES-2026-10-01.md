**Getting the latest face service** (since M3 PR #7): rebuild it too,
`docker compose up -d --build face-recognition`, or every liveness verify
keeps answering `unverified`.

**Faces enrolled before 2026-10-30 have to be enrolled again.** M3 PR #14
switched the face model (dlib → ArcFace), and an old face hash can't be
compared with the new one. Until the student re-enrols, every face match
answers `null`: flagged for review on face-required sessions, never wrongly
rejected. The grading and demo setups start from an empty database, so this
only affects your local one. Either start fresh (`docker compose down -v`,
then reseed), or clear the old faces once so those students can enrol again
without a reset code:

```bash
docker exec saiv-postgres psql -U saiv -d saiv -c "UPDATE users SET face_embedding_hash = NULL, face_enrolled = false WHERE face_embedding_hash IS NOT NULL AND face_embedding_hash NOT LIKE '%a1f0';"
```

(The reset-code rule stays on.) If you run the face service's unit tests in a local venv, reinstall from
the root `requirements-test.txt` (dlib is gone, `onnxruntime` is new).

**Getting the latest backend:**
```bash
git pull
docker compose up -d --build backend   # rebuild: a stale image serves old code; migrations run on start
```

**Priority:** **Must** = broken or graded until done · **Should** = needed for
correct behaviour or to unlock a backend feature · **Decide** = group decision
first · Optional · FYI = no action, just be aware.
